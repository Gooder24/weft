# Contributing to Weft

Weft is a private project owned by Karchi. Changes are proposed as pull requests, so the checks in
`.github/workflows/accessibility.yml` run before a change is merged.

Before you open a pull request:

1. Read [ACCESSIBILITY.md](ACCESSIBILITY.md) for the accessibility expectations.
2. Run the checks from the [README](README.md#tests).
3. Complete the accessibility section of the pull request template.

Report an accessibility barrier with the **Accessibility barrier** issue template. Use the `accessibility` label,
`good first issue` for small, well-scoped tasks, and `help wanted` where expert help is needed.

Update a baseline only to record a problem that already has an issue. Never commit secrets, tokens, or screenshots
of private chats, mail or calendar entries.
